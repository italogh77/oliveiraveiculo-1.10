# Oliveira Veículos — A Agência Nº 1 de Maricá - RJ

Novo site institucional e showroom de alta conversão (CRO) da **Oliveira Veículos**, agência referência em seminovos e usados selecionados em Maricá - RJ.

Desenvolvido em **React 19, Vite, Tailwind CSS e Framer Motion**, focado em estética premium Dark Mode com Dourado, gatilhos mentais de confiança, showroom interativo com filtros e links diretos para WhatsApp.

---

## 💎 Identidade Visual e CRO

- **Tema:** Dark Mode de luxo (Preto Carbono `#060608` com Grafite e Dourado Ouro `#D4AF37`).
- **Gatilhos Mentais:** Melhores Taxas (% nos 6 maiores bancos), Procedência Garantida (100% periciado com laudo cautelar), Aprovação em 15 minutos e Localização nobre em Maricá.
- **Showroom com Filtros Reais:** Filtre os veículos em tempo real por Marca, Modelo e Ano com transições suaves do Framer Motion.
- **Lead Generation Direto:** Cada veículo possui o botão *"Tenho Interesse"* que abre o WhatsApp já com a mensagem personalizada contendo o nome e ano do carro.
- **Prova Social "Momento Oliveira":** Bento Grid com histórias de clientes felizes recebendo seus carros com o tradicional laço vermelho gigante.
- **Botão Flutuante de WhatsApp:** Presente em toda a rolagem para nunca perder um lead qualificado.

## 🛠️ Como Rodar o Projeto

1. Instalar as dependências:
   ```bash
   npm install
   ```

2. Iniciar o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Gerar a build de produção:
   ```bash
   npm run build
   ```
